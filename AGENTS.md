# Project Instructions

## Project Overview
A REST API built using Node.js and Express 5.

## Technology Stack
- Node.js
- Express.js 5
- JavaScript ES Modules
- Zod
- Node.js built-in test runner

## General Coding Guidelines
- Use JavaScript only. Do not introduce TypeScript.
- Follow the existing project architecture.
- Use ES modules.
- Keep route handlers separate from business logic.
- Avoid unnecessary dependencies.
- Use meaningful names.

## Development Workflow
- Inspect existing code before making changes.
- Follow applicable rules in the repository.
- Add or update tests for code changes.
- Run npm test after implementation.
- Summarize changes and test results.
